# SAMPLE / 示例: A handoff note that survives a pause

This fictional editorial scenario concerns a handoff note. It describes no real team and offers no measured results. An editor opens an older draft and finds a date, a title, and several unresolved comments. Those items show that work happened, but they do not explain what the next contributor should do.

## Start with the decision

Imagine the draft contains two competing openings. One introduces a broad problem; the other begins with a specific reader question. The previous editor has left both in place. A useful note would say which opening is provisional and why. Without that explanation, a contributor might polish a paragraph that the team intended to remove.

## Keep uncertainty visible

The next note should name an unresolved question. For example, the second section may suggest that every draft needs a scheduled meeting. That suggestion has no supporting evidence in this fictional example. The editor can narrow it to a possible practice, explain the context, or remove it. A length check cannot make that editorial decision.

## Leave a usable next action

For this example, the next action is to rewrite the second section around one reader question and leave the uncertain recommendation flagged for review. Assign the task to a role that can accept it, then agree on a date. If the role is unassigned, preserve that gap rather than inventing an owner. When the work resumes, check whether the original audience still fits.

## Close the loop

Keep the original reason beside the revision so a reviewer can compare the change with the request. A completed edit is not the same as approval. The human reviewer still decides whether the argument, language, and permissions are ready. Try the note on one fictional draft before adopting the format more broadly.

Before any real posting, a human should check destination rules and review the wording. This SAMPLE remains an illustrative adaptation, not publication authorization.
