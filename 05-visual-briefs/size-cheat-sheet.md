# Image planning cheat sheet

Local starting sizes, not guaranteed platform specifications. Check the destination editor before export. Use safe margins, readable text, alt text, and licensed assets.

| Platform | Starting size / guidance |
| --- | --- |
| wechat | 900 × 383, about 2.35:1; keep essential text centered. |
| x | 1600 × 900, 16:9; keep text readable on mobile. |
| medium | 1600 × 900, 16:9; add alt text and credit. |
| linkedin | 1200 × 1200, 1:1; use generous safe margins. |
| reddit | 1200 × 900, 4:3 if images are allowed; text-only is often appropriate. |
