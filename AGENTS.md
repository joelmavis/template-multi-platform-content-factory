# Workspace instructions

Public template. All examples are fictional.

Read README.md and 99-system-rules before editing. Keep this workspace company-agnostic and offline. Use placeholders, fictional examples, and example.com if a URL is necessary. Never introduce personal data, accounts, credentials, or unsupported product claims.

Maintain one shared topic brief and five audience-specific drafts. Use the platform guides and platform-rules.json. Keep CSV and draft metadata aligned; regenerate HTML after board changes. Run `python3 scripts/content_factory.py check`, `python3 scripts/content_factory.py build --check`, and `python3 -m unittest discover tests` before handoff.

AI drafts and suggests edits. Humans review, approve, move content to final/published, and publish manually. AI never publishes or marks its own work approved. Do not treat sample records as real approval.
